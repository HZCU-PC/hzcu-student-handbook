# 前沿科技论文

## AI 论文双轨时间线（1986—2026）

四十年、45 篇论文，按两种判据分两条轨并排读：

- **B 轨 · 突破轨**（20 篇）：改变了整个领域走向的那一次跃迁，附评分与影响说明。
- **F 轨 · 前沿轨**（25 篇）：正在把边界往外推的工作，标注它解决的具体问题。

时间轴不是等距的：1986—2011 的 26 年只占轴宽 30%，2012—2026 的 15 年占 70%——前段能看清「稀疏」本身，后段才读得清标签。

### 使用方式

- **时间线工作台**：横向滚动即时间，纵向两层即双轨。悬停看摘要，点击进入论文详情，支持「41 年 / 标准 / 十年」三档缩放与轨道、时代筛选。
- **论文详情页**：三问结构（解决了什么、怎么做的、留下了什么），并给出原文出处、知网镜像与 Semantic Scholar 检索三个入口。
- **论文站点导航**：预印本、出版方、国内与工具三类常用学术站点，含各发表处分布统计。

> 站点为纯静态页面（无构建、无框架、无后端），不依赖 MkDocs 运行时，随本站一同发布；也可打包后直接双击 `index.html` 离线阅读。
